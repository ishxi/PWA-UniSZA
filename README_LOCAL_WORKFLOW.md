
# Job Workflow Demo (Local Storage)

Sistem ini kini menggunakan LocalStorage untuk:

- Job posting
- Applications
- Ratings

Tiada Supabase digunakan supaya demo berjalan tanpa konfigurasi.

## Workflow

1. Employer create job
2. Student apply
3. Employer approve / reject
4. Student submit work
5. Employer rate student (optional)
6. Job closed

Bahasa: English + Bahasa Melayu
